# Future Me — 寫給未來的自己

一個只存在你這台 Mac 上的「未來信」App。
信寫在 App 裡、用你的主密碼加密存在硬碟、到期時由 App 自己彈出來。
沒有伺服器、沒有帳號、沒有網路連線，任何一個字都不會離開這台電腦。

## 系統需求

- macOS 13 以上（只支援 Mac；排程與常駐用的是 macOS 的 launchd）
- Apple Silicon（M 系列）與 Intel Mac 都可以，同一個通用版 .dmg

## 安裝

1. 到 GitHub 的 右側面板的**Releases** 下載 `Future Me-<版本>-universal.dmg`，打開後把 `Future Me.app` 拖到「應用程式」。
2. **這個 App 沒有 Apple 的付費簽章**，所以第一次打開 macOS 會擋。請這樣做：
   - 先雙擊一次（會出現「無法打開」）
   - 打開「系統設定 → 隱私權與安全性」，往下捲到底，會看到「Future Me 已被阻擋」→ 按「**仍要打開**」
   - 或在終端機執行下面這行，把下載時加上的隔離標記拿掉，之後就能直接開：
     ```bash
     xattr -dr com.apple.quarantine "/Applications/Future Me.app"
     ```
   只需要做這一次。
3. 首次啟動會要你設主密碼與密碼提示，並詢問要不要「登入時自動開啟」。
   建議打開，信才會在你沒想到的時候準時出現。
4. 第一次跳通知時 macOS 會問要不要允許「Future Me」的通知，請按允許。
5. 第一次打開後，App 會把自己登記給 macOS 的 launchd 看管，之後雙擊圖示只是把視窗叫出來。

## 安全性，一次講清楚

- 信的正文與反思用主密碼加密（scrypt 派生金鑰 + AES-256-GCM），硬碟上只有密文。
- 明文只有：信封層（日期、標題、引言、狀態）與密碼提示。不想留痕跡，標題與引言可以留空。
- 主密碼與金鑰只存在記憶體，15 分鐘沒用自動清除（可調），不寫進任何檔案或記錄。
- App 沒有任何網路功能：程式碼裡沒有 fetch、沒有更新檢查、沒有分析回報，介面層還用 CSP 禁止連線。
- 記錄檔 `~/Library/Logs/Future Me/app.log` 只有事件（啟動、送達、結束），沒有信的內容。
- 忘記主密碼沒有任何救援方式。

## 開發

```bash
npm install     # 第一次
npm start       # 開發模式啟動
npm test        # 加密、儲存、排程的單元測試
npm run build   # 打包：dist/mac-arm64/Future Me.app + 通用版 .dmg（Apple Silicon 與 Intel 都能用）
```

開發或測試時可以把資料夾指到別處，不動到真正的信箱：

```bash
FUTURE_LETTER_DATA_DIR=/tmp/future-me-test npm start
```

## 資料在哪裡

```
~/Future Me/
├── config.json          設定
├── vault.json           主密碼驗證檔（鹽、canary、密碼提示）
├── index.json           信封層：日期、標題、引言、狀態（明文）
└── letters/<id>.sealed  信紙：正文密文（AES-256-GCM）
```

- **備份**：Time Machine 就好。檔案本身已加密，備份到外接硬碟沒有隱私問題。
  也可以在 App 的「設定 → 備份整個信箱」存成一個 zip。
- **換電腦**：新電腦裝好 App 但先不要打開；把備份 zip 解壓縮（或把整個資料夾複製）成新電腦的 `~/Future Me/`，
  再打開 App，輸入同一組主密碼就能接著用，在途的信會照原定時間送達，錯過的會立刻補送。
  信件、反思、設定、密碼驗證檔全部都在這個資料夾裡，沒有別的地方。
- **不建議**放進 iCloud / Dropbox / Google Drive 同步的資料夾。雖然加密了，但這違背「完全在自己電腦」的初衷。

## 寫信

- 每次打開寫信頁會隨機抽一款信紙（橫線信紙、夜空、櫻花、舊信箋），不喜歡就按「換一張信紙」。
- 封存時會記住你用的信紙，未來拆信時會用同一款顯示。
- 信箱的底圖在 `src/renderer/img/inbox-bg.jpg`，換一張同名的圖再重新打包就能換底圖。
- App 圖示是程式畫的手繪風信封：`node scripts-make-app-icon.js` 會重新產生 `assets/icon.png`；選單列圖示用 `node scripts-make-icons.js`。

## 讀完信之後

拆開信讀完，信紙下方有三個選擇：

- **收好**：關掉，信留在「已拆封」，隨時可以再讀。
- **寫下反思**：讀完之後想對那時候的自己說的話。跟信一樣用主密碼加密，存在信的旁邊（`letters/<id>.reflection.sealed`），之後再讀這封信會一起顯示，也可以「再寫一點」。
- **刪除這封信**：覺得沒什麼就直接刪掉。信和反思一起永久刪除，會先確認一次。

## 一定要知道的事

1. **忘記主密碼 = 所有信永遠打不開。** 沒有後門、沒有救援。提示請寫只有你懂的東西。
2. **App 要在執行中才會準時彈出。** 選單列有一個信封圖示代表它在背景等著；關掉視窗不會結束 App。
   App 由 macOS 的 launchd 看管（`~/Library/LaunchAgents/com.claire.future-me.plist`）：登入時自動啟動，
   若當機或被強制結束會在 10 秒內自動重啟。按 Cmd+Q 會先跳確認，確認結束後要到下次登入或重新打開才會再跑，
   重新打開時會立刻補送所有錯過的信。
   出問題時看記錄檔：`~/Library/Logs/Future Me/app.log`（只記事件，不記信件內容）。
3. 電腦睡眠或關機期間到期的信不會漏掉，喚醒或開機後會立刻補送。
4. 信到期彈出的信封視窗會釘在所有視窗最上層、跟著你到每個桌面，直到你按「拆開信紙」。
   如果你先把它關掉，它會在 App 下次啟動時、以及每天的提醒時間再出現（時間可在設定調整）。
5. 不管從 Dock、Cmd+Q 還是選單列「結束」，都會先跳確認，避免誤關。

## 更換主密碼

設定 → 主密碼。輸入舊密碼與新密碼後，所有信件會用新密碼重新加密。
更換過程中請不要關閉 App。
